# Native English Trainer

세 가지 모드로 영어 회화를 훈련하는 개인용 웹앱.
빌드 도구도, 서버도, 계정도 없다. 브라우저만 있으면 된다.

| 모드 | 다루는 장면 |
| --- | --- |
| ☕ 일상회화 | 카페 주문, 근황 대화, 가족 식탁, 컨디션 설명, 약속 조율 |
| ✈️ 여행회화 | 입국심사, 호텔 체크인·클레임, 식당 주문, 길찾기, 분실·환불 |
| 🎬 영화 비즈니스 회화 | 피칭 미팅, 마켓 네트워킹, 공동제작 협상, 현장 연출, 세일즈·계약 |

각 모드에 5개 장면, 장면마다 10~12줄의 대화와 6~8개의 핵심 표현이 들어 있다.

## 학습 방식

장면마다 세 개의 탭이 순서대로 이어진다.

1. **대화** — 전체 듣기, 문장별 듣기, 0.65배속 느리게 듣기, 한글 가리기.
   마이크 버튼을 누르면 따라 말한 문장이 단어 단위로 채점된다.
2. **표현 카드** — 영어를 먼저 보고 뜻을 떠올린 뒤 확인한다.
   "입에서 나온다"와 "아직 애매"로 스스로 채점하면 간격 반복이 다음 날짜를 정한다.
3. **롤플레이** — 한쪽 역할을 맡으면 상대 대사는 자동으로 재생된다.
   내 차례에는 한국어 힌트만 보이고, 영어는 스스로 만들어 말해야 한다.

## 간격 반복

라이트너 5박스 방식이다. 맞히면 다음 박스로 올라가며 복습 간격이 **1일 → 3일 → 7일 → 16일 → 35일**로 늘어나고,
틀리면 1번 박스로 되돌아간다. 홈 화면의 "오늘의 복습"은 약한 카드와 오래 밀린 카드를 앞세워 한 번에 20장까지 꺼내온다.

하루 목표치와 연속 학습일이 함께 기록된다. 목표는 설정에서 바꾸면 된다.

## 실행

가장 간단한 방법은 저장소 폴더에서 로컬 서버를 하나 띄우는 것이다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`index.html`을 더블클릭해서 열어도 듣기와 카드 학습은 그대로 작동한다.
다만 **말하기 채점(음성 인식)은 https 또는 localhost에서만** 브라우저가 마이크를 열어준다.
GitHub Pages에 올리면 휴대폰에서도 바로 쓸 수 있다.

### 브라우저별 지원

| 기능 | Chrome / Edge | Safari | Firefox |
| --- | --- | --- | --- |
| 듣기(TTS) | ✅ | ✅ | ✅ |
| 말하기 채점(음성 인식) | ✅ | ⚠️ 일부 버전 | ❌ |

말하기 채점을 쓸 거라면 크롬 계열을 권한다.

## 저장되는 것

학습 기록은 전부 브라우저의 `localStorage`(키: `hykai-english-v1`)에만 남는다.
목소리도 문장도 외부로 나가지 않는다. 기기를 바꾸면 기록은 따라오지 않고,
설정 화면의 "기록 초기화"로 언제든 지울 수 있다.

## 내용 추가하기

`js/data/` 아래 세 파일이 학습 내용의 전부다. 장면 하나를 추가하려면 `scenes` 배열에 객체를 하나 더 넣으면 된다.

```js
{
  id: 'film-vfx',                  // 저장소 키로 쓰이므로 고유해야 한다
  title: '후반작업 미팅',
  titleEn: 'Post-production meeting',
  situation: '어떤 상황인지 한 줄 설명',
  lines: [
    { s: 'You', en: 'English line.', ko: '한국어 뜻', tip: '왜 이렇게 말하는지 (선택)' }
  ],
  expressions: [
    { en: 'key expression', ko: '뜻', note: '쓰임새 메모' }
  ]
}
```

`lines`의 `s`(화자) 중 하나를 `'You'`로 두면 롤플레이에서 기본 역할이 된다.
새 모드를 통째로 만들려면 `js/data/`에 파일을 하나 추가하고 `index.html`의 스크립트 목록에 넣으면 끝이다.

## 파일 구조

```
index.html            화면 뼈대와 스크립트 로딩
assets/style.css      전체 스타일
js/data/daily.js      일상회화 콘텐츠
js/data/travel.js     여행회화 콘텐츠
js/data/film.js       영화 비즈니스 회화 콘텐츠
js/store.js           localStorage, 스트릭, 하루 목표
js/srs.js             라이트너 간격 반복
js/speech.js          음성 합성·인식과 단어 단위 채점
js/app.js             화면 렌더링과 학습 흐름
```
