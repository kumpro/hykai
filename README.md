# Native English Trainer

회화·문법·듣기시험·피칭 연습을 한 곳에서 굴리는 개인용 웹앱.
빌드 도구도, 서버도, 계정도 없다. 브라우저만 있으면 된다.

## 모드

### 회화 모드 (장면 기반)

| 모드 | 다루는 장면 | 테마 |
| --- | --- | --- |
| ☕ 일상회화 | 카페 주문, 근황 대화, 가족 식탁, 컨디션 설명, 약속 조율 | 현대 |
| ✈️ 여행회화 | 입국심사, 호텔 체크인·클레임, 식당 주문, 길찾기, 분실·환불 | 근대 |
| 🎬 영화 비즈니스 회화 | 피칭 미팅, 마켓 네트워킹, 공동제작 협상, 현장 연출, 세일즈·계약 | 미래 |
| 🧩 후크 문구 반복 | 문장을 붙이는 접착제 표현 12개 (`The thing is…`, `Any chance you could…?`) | 고대 |
| ⚡ 신조어·최신 표현 | 업무 은어(circle back, bandwidth)와 또래 표현(no cap, it's giving) | 미래 |
| 📝 내 작품 피칭 | 로그라인을 입력해 직접 만든 장면 | 미래 |

장면마다 세 개의 탭이 순서대로 이어진다.

1. **대화** — 전체 듣기, 문장별 듣기, 0.62배속, 한글 가리기, 영/미 전환, 문장별 발음 채점
2. **표현 카드** — 영어를 먼저 보고 뜻을 떠올린 뒤 확인. 자가 채점이 다음 복습 날짜를 정한다
3. **롤플레이** — 상대 대사는 자동 재생, 내 차례에는 **한국어 힌트만** 보고 영어를 스스로 만든다

## 영국식 / 미국식

설정에서 발음 기준을 바꾸면 두 가지가 함께 움직인다.

- **소리** — `en-GB` 또는 `en-US` 목소리를 골라 재생하고, 음성 인식도 같은 기준으로 받는다
- **표기** — 화면의 영어를 철자와 어휘까지 바꿔 보여준다 (`color→colour`, `elevator→lift`, `Could we get the check→the bill`)

뜻이 갈리는 단어(`check`, `line`, `fall`, `practice`, `schedule`)는 일부러 변환에서 뺐다.
영화 대사의 `line`을 `queue`로 바꾸면 곤란하기 때문이다. `schedule`처럼 발음만 다른 단어는
카드 뒷면에 발음 메모가 붙는다.

## 대화 상대 목소리

여덟 가지 인물 프로필이 있다. 브라우저가 주는 음성에 피치와 속도를 얹어 결을 만든다.

🎭 배우 · 🌸 애니메이션 · 👤 일반 남성 · 👤 일반 여성 · 🧒 유아 · 🧑 청소년 · 💼 임원·바이어 · 🎙️ 내레이터

대화 탭과 롤플레이 화면에서 바로 바꿀 수 있다. 듣기 시험만은 항상 내레이터로 재생된다 —
시험에서는 또렷한 발음이 우선이다. 기기에 해당 목소리가 없으면 피치와 속도로 흉내 낸다.

## 간격 반복

라이트너 5박스. 맞히면 간격이 벌어지고, 틀리면 1번 박스로 되돌아간다.
홈의 "오늘의 복습"은 약한 카드와 오래 밀린 카드를 앞세워 하루 20장까지 꺼낸다.
100장이 밀려 있어도 20장만 보여주는 이유는, 한꺼번에 들이밀면 사흘 만에 그만두기 때문이다.

간격은 설정에서 두 가지 중 고른다.

| 프리셋 | 1 → 2 → 3 → 4 → 5단계 | 언제 |
| --- | --- | --- |
| 표준 | 1 · 3 · 7 · 16 · 35일 | 첫 인출이 웬만큼 되는 표현 |
| 촘촘 | 1 · 2 · 4 · 10 · 24일 | 초반에 자꾸 놓칠 때 |

촘촘 쪽은 앞 단계만 좁히고 뒤는 그대로 벌려뒀다. 초반을 촘촘하게 하면서 뒤까지 좁히면
총 복습량이 눈덩이처럼 불어나 며칠 만에 감당이 안 된다.

## 피칭 스튜디오

작품 제목, 로그라인, 후크, 레퍼런스 두 편, 예산 규모, 진행 단계, 배급 방향을 넣으면
16줄짜리 피칭 미팅 장면과 13줄짜리 네트워킹 대화가 만들어진다.

네트워킹 대화는 3분을 다섯 단계로 나눈다 — 진입 → 자기소개 → 한 줄 피칭 → 상대 파악 → 후속 약속.

만들어진 장면은 `📝 내 작품 피칭` 모드에 들어가고, 다른 장면과 똑같이 롤플레이하고 복습할 수 있다.
전부 브라우저 안에서 규칙 기반으로 조립되며, 입력한 내용은 어디로도 전송되지 않는다.

영어로 넣은 문장은 그대로 대사가 되고 그대로 읽힌다. 로그라인과 후크는 영어로 다듬어 넣는 편이 낫다.

## 신조어 팩 갱신

내장 팩은 버전과 갱신일을 갖고 있다. 설정 → **신조어 팩 갱신**에서 세 가지 방법으로 바꿀 수 있다.

- JSON 주소를 넣어 불러오기 (해당 서버가 CORS를 허용해야 한다)
- 같은 주소를 등록해두고 **하루 한 번 자동 확인** — `version`이 올라갔을 때만 교체한다.
  실패하면 아무 일도 일어나지 않는다. 학습이 멈추면 안 되기 때문이다.
- JSON을 직접 붙여넣기

```json
{
  "version": 2,
  "updated": "2026-10-01",
  "source": "직접 추가",
  "items": [
    { "en": "circle back", "ko": "나중에 다시 논의하다", "note": "회의에서 결론을 미룰 때.", "register": "work" }
  ]
}
```

`register`는 `work`(업무) 또는 `casual`(또래). 팩을 바꾸면 장면이 다시 만들어지고 복습 큐에도 반영된다.
기본 팩으로 되돌리는 버튼도 같은 화면에 있다.

## 내보내기와 자동 발송

학습 점검 화면에서 오늘 복습할 표현을 텍스트로 뽑을 수 있다.

- **클립보드로 복사** — 카카오톡 "나에게 보내기"에 붙여넣으면 그대로 쓸 수 있다
- **메일로 보내기** — `mailto:` 링크로 기본 메일 앱을 연다 (분량이 많으면 자동으로 복사로 전환)
- **텍스트 파일로 저장**

정해진 시각에 알아서 오게 하려면 바깥에서 깨워줄 스케줄러가 필요하다.
`automation/n8n-daily-english.json`이 그 워크플로우다 — 매일 아침 8시에 12개를 골라
Gmail과 카카오톡으로 보낸다. 설정 방법은 [`automation/README.md`](automation/README.md)에 있다.

앱 자체는 브라우저 밖으로 아무것도 보내지 않는다. 발송은 전적으로 n8n 쪽 일이다.

## 화면 테마

모드마다 시대가 다르다 — **고대**(파피루스와 금), **중세**(양피지와 진홍), **근대**(아르데코 청록과 황동),
**현대**(편집실 조명), **미래**(네온 시안). 색뿐 아니라 배경 질감, 제목 서체, 모서리 처리까지 함께 바뀐다.
설정에서 하나로 고정할 수도 있다.

## 실행

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`index.html`을 더블클릭해서 열어도 듣기와 카드 학습, 시험, 드릴은 그대로 작동한다.
다만 **말하기 채점(음성 인식)은 https 또는 localhost에서만** 브라우저가 마이크를 열어준다.

## 휴대폰에 설치하기

저장소 **Settings → Pages → Source**를 `GitHub Actions`로 바꾸고 푸시하면
`.github/workflows/pages.yml`이 사이트를 배포한다.

배포된 주소를 휴대폰에서 열고 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 설치된다.
서비스 워커가 앱 파일 전체를 캐시해두기 때문에 지하철에서도 열린다 —
듣기, 카드, 시험, 문법 드릴은 오프라인에서 그대로 돌아간다.
출퇴근길 20분이 하루 목표를 채우기에 딱 맞는 분량이고, 그게 이 앱의 제자리다.

## 저장되는 것

학습 기록은 전부 브라우저의 `localStorage`(키: `hykai-english-v1`)에만 남는다.
목소리도, 문장도, 입력한 로그라인도 외부로 나가지 않는다. 기기를 바꾸면 기록은 따라오지 않고,
설정의 "기록 초기화"로 언제든 지울 수 있다.

## 내용 추가하기

`js/data/` 아래 파일이 학습 내용의 전부다. 장면 하나를 추가하려면 해당 팩의 `scenes` 배열에 객체를 하나 더 넣는다.

```js
{
  id: 'film-vfx',                  // 저장소 키로 쓰이므로 고유해야 한다
  title: '후반작업 미팅',
  titleEn: 'Post-production meeting',
  situation: '어떤 상황인지 한 줄 설명',
  lines: [
    { s: 'You', en: 'English line.', ko: '한국어 뜻', tip: '왜 이렇게 말하는지 (선택)' }
  ],
  expressions: [
    { en: 'key expression', ko: '뜻', note: '쓰임새 메모' }
  ]
}
```

`lines`의 `s`(화자) 중 하나를 `'You'`로 두면 롤플레이에서 기본 역할이 된다.
새 모드를 통째로 만들려면 `js/data/`에 파일을 추가하고 `index.html`의 스크립트 목록에 넣으면 끝이다.
후크 문구와 신조어는 `js/data/derived.js`가 자동으로 장면 형태로 감싸주므로,
`focus.js`와 `slang.js`에 항목만 추가하면 된다.
