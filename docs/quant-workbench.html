자기자본 전용 · 저빈도 팩터

데이터 → 전략 → 백테스트 → 포트폴리오 → 페이퍼 트레이딩. 브라우저에서 완결되는 P0~P3 실행 도구.

데이터층 (P0)

KRX 월말 데이터(종가·PER·PBR·ROE·시가총액)를 불러옵니다. 실데이터는 pykrx로 추출한 CSV를 임포트하세요.

불러온 데이터가 없습니다.

CSV 형식

헤더 필수. 한 종목·한 월 = 한 행. 월말 데이터 권장.

date,ticker,name,close,per,pbr,roe,marketcap 2024-01-31,005930,삼성전자,74000,15.2,1.4,9.8,441000000000000 2024-01-31,000660,SK하이닉스,138000,22.1,1.9,7.1,100000000000000 ...
pykrx로 CSV 만드는 예시 코드 import pandas as pd from pykrx import stock dates = stock.get_previous_business_days(year=2024) # 월말만 골라 사용 rows = [] for d in month_end_dates: # 'YYYYMMDD' df = stock.get_market_fundamental(d, market="KOSPI") # PER/PBR/... cap = stock.get_market_cap(d, market="KOSPI")["시가총액"] ohlcv = stock.get_market_ohlcv(d, market="KOSPI")["종가"] for tk in df.index: rows.append([f"{d[:4]}-{d[4:6]}-{d[6:]}", tk, stock.get_market_ticker_name(tk), ohlcv.get(tk), df.loc[tk,"PER"], df.loc[tk,"PBR"], 0, cap.get(tk)]) # ROE는 별도 소스로 채우기 pd.DataFrame(rows, columns=["date","ticker","name","close","per","pbr","roe","marketcap"])\ .to_csv("krx_monthly.csv", index=False, encoding="utf-8-sig")

검증층 (P1) — 백테스트

룩백 이후 시점부터 리밸런싱하며 월별 시가평가. 손절 -기준 도달 시 현금화. 벤치마크 = 전체 동일가중.

데이터를 불러오고 [백테스트 실행]을 누르세요. 하락장이 포함된 기간일수록 신뢰도가 높습니다.

실주문(KIS OpenAPI) 연동 — 왜 브라우저만으로는 안 되는가

appKey / appSecret은 브라우저에 두면 안 됩니다. 노출 시 계좌 탈취 위험이 있고, 증권사 API는 CORS로 브라우저 직접 호출을 막습니다. 따라서 실주문은 서버 프록시(백엔드)가 담당하고, 이 웹앱은 그 프록시에 주문 의도만 전달하는 구조여야 합니다.

P4 실계좌용 백엔드 프록시 최소 구조 (참고) # 서버(예: FastAPI). 키는 서버 환경변수에만 존재. # 1) 토큰 발급 POST /oauth2/tokenP (appkey, appsecret) -> access_token # 2) 주문 실행 POST /uapi/domestic-stock/v1/trading/order-cash # headers: authorization: Bearer , appkey, appsecret, tr_id # body: { CANO, ACNT_PRDT_CD, PDNO: 종목코드, ORD_DVSN, ORD_QTY, ORD_UNPR } # # 웹앱 → 서버: POST /api/rebalance { orders:[{ticker, side, qty}] } # 서버가 모의투자(vts) 또는 실전(prod) 도메인 선택해 대리 호출. # 규칙: 자기자본 전용 · 초당 호출 제한 준수 · 손절 -15% 서버측 이중 체크.

도움말

사용 순서

① 데이터 불러오기 → ② 전략 가중치 저장 → ③ 백테스트로 검증 → ④ 최신 추천 확인 → ⑤ 페이퍼로 모의 운용. 설정·데이터·모의계좌는 이 브라우저에 자동 저장됩니다.

팩터 정의

  • 밸류 — 이익수익률(1/PER) 높을수록 우대(저평가).
  • 모멘텀 — 룩백 기간 수익률 높을수록 우대.
  • 퀄리티 — ROE 높을수록 우대.
  • 로우볼 — 최근 수익률 변동성 낮을수록 우대.
  • 사이즈 — 시가총액 작을수록 우대(소형주).

지표

  • CAGR 연평균 복리수익률 · MDD 최대낙폭 · 샤프 위험대비수익(무위험 0 가정) · Calmar CAGR/|MDD| · 승률 월수익 양(+) 비율.
과거 성과·합성 데이터는 미래 수익을 보장하지 않습니다. 실계좌(P4) 전환은 3개월 페이퍼 트레이딩(P3) 검증 뒤에만 판단합니다.
